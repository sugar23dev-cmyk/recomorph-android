# RecoMorph（Android 版）

学習ノートと復習のアプリ RecoMorph の Android 版です。
Google Play には出していないので、ここから APK を直接入れます。
iPhone の方は [App Store](https://apps.apple.com/jp/app/recomorph/id6825617097) からどうぞ。

## ダウンロード

**[最新版をダウンロード（recomorph.apk）](https://github.com/sugar23dev-cmyk/recomorph-android/releases/latest/download/recomorph.apk)**

- 約 170MB あります。Wi-Fi でのダウンロードをおすすめします。
- 64bit（arm64）の端末専用です。ここ数年の Android スマホならほぼ対応しています。

## はじめて入れるとき

1. 上のリンクをスマホのブラウザで開き、ダウンロードします。
2. ダウンロードした `recomorph.apk` を開きます。
3. 「この提供元のアプリを許可」の画面が出たら許可して、戻ります。
4. 「インストール」を押します。

Play プロテクトの警告が出た場合は、「詳細」から「インストールする」を選んでください。

## 更新するとき

同じリンクから新しい `recomorph.apk` をダウンロードして開き、「更新」を押します。
ノートや復習の記録はそのまま残ります。

**アンインストールしてから入れ直さないでください。** 端末に保存したデータが消えます。
